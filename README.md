# 🧾 INVOXA — Freelancer Invoice Manager

A web-based invoice management system developed using Flask and web technologies to help businesses generate GST invoices and manage client and payment records efficiently.

---

## 🚀 Features

- Add and manage client information  
- Create invoices with multiple items  
- Automatic tax calculation  
- Track invoice status (Paid / Unpaid / Overdue)  
- Generate and download PDF invoices  
- Dashboard with basic revenue insights  
- SQLite database for data storage  

---

## 🛠️ Tech Stack

- **Backend**: Python (Flask)  
- **Database**: SQLite  
- **PDF Generation**: ReportLab  
- **Frontend**: HTML, CSS, JavaScript  

---

## ⚙️ Setup Instructions

### 1. Install dependencies
```bash
pip install flask reportlab
```
### 2. Run the application
```bash
python app.py 
```
### 3. Open in browser
```bash
http://localhost:5000
```
